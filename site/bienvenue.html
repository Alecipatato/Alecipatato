RappelPro

Merci ! Votre abonnement est actif.

Il reste 5 minutes pour que plus aucun appel manqué ne vous échappe.

  1. Surveillez vos textos

    Dans la minute, vous recevez sur votre cellulaire votre numéro RappelPro. Gardez ce texto : il contient le code exact à composer.

  2. Activez le transfert des appels manqués

    Sur le cellulaire du commerce, composez ce code en remplaçant les X par votre numéro RappelPro, puis appuyez sur Appeler :

    **004*+1XXXXXXXXXX#

    Ça fonctionne chez la plupart des opérateurs (Bell, Telus, Rogers, Vidéotron, Fido, Koodo, Virgin, Freedom). Les appels sont transférés seulement quand vous ne répondez pas, êtes occupé ou hors réseau. Pour désactiver : ##004#

    Ligne fixe ? Appelez votre fournisseur et demandez le « renvoi d'appel sur non-réponse et sur occupation » vers votre numéro RappelPro. N'utilisez pas le renvoi de tous les appels : votre téléphone ne sonnerait plus.

  3. Faites un test

    Depuis un autre téléphone, appelez votre commerce et ne répondez pas. Le téléphone de test reçoit le texto de RappelPro, et vous recevez une alerte avec son numéro.

  4. Demandez des avis Google

    Après un service, textez à votre numéro RappelPro :

    AVIS 514-555-1234 Julie

    Votre client reçoit aussitôt un texto avec le lien vers votre page d'avis.
